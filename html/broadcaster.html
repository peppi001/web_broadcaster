Web Broadcaster

              
Web Broadcaster is an advanced radio automation and streaming platform designed for 24/7 operation.

              
It combines dual-deck playback, automatic cue detection, intelligent crossfading, internet stream integration, metadata processing, and flexible playlist management into a single easy-to-use application.

              
Powered by Python, the native Web Broadcaster audio engine, and SQLite for reliable, high-quality audio delivery.
